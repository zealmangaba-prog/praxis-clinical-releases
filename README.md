# Praxis Clinical

**Praxis Clinical** is a local-first, privacy-focused clinical report and documentation generator for registered practitioners. All data processing occurs locally on your machine—no client records or notes leave your computer.

## Installation Guide

### Windows

1. Download **`Praxis_Clinical_Setup.exe`**.
2. Double-click the downloaded setup file to launch the installation wizard.
   > **Note on Windows SmartScreen:**  
   > Because this is a newly published medical software release, Windows may show a blue banner reading *"Windows protected your PC"*.  
   > Click **More info**, then select **Run anyway** to proceed.
3. Follow the on-screen prompts to complete the installation.
4. Launch the application via the **Praxis Clinical** shortcut on your Desktop or Start Menu.

---

### macOS

1. Download **`Praxis_Clinical_Installer.dmg`**.
2. Double-click the `.dmg` file to open it, then drag **Praxis Clinical** into your **Applications** folder.
3. **First Launch (macOS Gatekeeper):**
   * Go to your **Applications** folder in Finder.
   * **Right-click (or Control-click)** on **Praxis Clinical** and select **Open**.
   * A security dialog will appear stating Apple cannot verify the developer. Click **Open** to proceed.
4. Subsequent launches can be done normally with a regular double-click from Launchpad or Applications.

## Key Features

- **Local-First Privacy:** Runs entirely on localhost; your client data stays encrypted and offline on your machine.
- **Medical Scheme Alignment:** Tailored section formatting, progress indicators, and ICD/billing code structures.
- **Standard Exports:** Clean, formatted output ready for Word (`.docx`) and PDF review.
- **Offline Reliability:** No active internet connection required to generate or review reports.
